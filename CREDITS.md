# Credits

Every third-party asset under `assets/` (anything not produced by `tools/art/build_all.py` or `tools/audio/build_sfx.py`) has one row here, added in the same commit as the file. Allowed licenses: CC0, CC-BY 3.0/4.0, OFL, or an explicit free-for-commercial-use license. See `specs/SPEC-art-audio.md`, "Sourced assets". `tests/integration/test_credits.gd` checks this table against `assets/`.
