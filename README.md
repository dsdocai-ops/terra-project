**This project is:**
- A roguelike action game, in the Godot engine
- The game focuses on having players dive into a cave and slowly descend through the floors, similar to a dungeon crawler

**How the project what built:**
- I along with my co-developer used Claude code to develop the game
- Neither of us have the ability to code, so we used AI to help with the project
- The idea came from my co-developer
- He has now quit the project due to being too busy
- The project is now solely developed by myself
- The game is coded in the Godot Engine
- It is in a 2.5d isometric pixel art style

**How to run the game:**
- To run the game, go to https://github.com/dsdocai-ops/terra-project/releases/tag/week-1-demo
- Listen to the instructions listed
- Install
- unzip the file or run the .exe
- Then play!
