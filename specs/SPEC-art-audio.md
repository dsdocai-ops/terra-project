# Spec: art-audio

| | |
|---|---|
| Module id | `art-audio` |
| Owner | Both |
| Weeks | 1 (pipeline, placeholders, AudioManager stub), 6 (first real tiles and player sheet, Biome 1 track, hit SFX set), 12 (final art, VFX, audio pass) |
| Design doc | section 17, section 20 (week 12), section 6 (hit feedback) |
| Depends on | `foundation` |
| Depended on by | every module with visuals or sound |

## Objective

A pipeline that lets both developers (and Claude Code for data) drop in pixel art, particles, music, and SFX without touching logic, placeholder-first so systems ship on schedule, with a final pass in week 12.

## Scope

### Pixel art pipeline

- Isometric 2:1 tiles, 64x32 base; wall tiles 64x64 with the top 32 px as the face. Atlas PNGs per biome under `assets/tilesets/<biome>/`, import preset `pixel` (filter nearest, no mipmaps, lossless).
- Characters: 8-direction sprite sheets, frame 48x48 for players and humanoid enemies, 32x32 small, 96x96 large, 192x192 bosses. Row order `s, sw, w, nw, n, ne, e, se`; animation columns `idle, walk, attack_light_1..n, attack_heavy, dodge, hit, downed, death`. `SpriteFrames` resources generated by a tool script `tools/make_sprite_frames.gd` (EditorScript) from a sheet plus a small JSON manifest, so adding a sheet never means hand-editing frames.
- Portraits 96x96. Icons 16x16 for relics, abilities, weapons, 32x32 for shop.
- Naming: `assets/sprites/<category>/<id>.png` where `<id>` matches the `ContentData.id`.
- Placeholders: `tools/make_placeholders.gd` generates colored diamond sprites with a facing arrow, lettered icons, and flat tiles so any new content has a visible stand-in on day one.
- Palette: per-biome `Gradient` in `BiomeData`; UI accents and VFX tints derive from it.

### Lighting

`CanvasModulate` per biome, `PointLight2D` on players and torches with a soft 64 px texture, enemy glow for elites; capped at 16 lights per room and pooled. Compatibility renderer: no shadows (cost), use faked ground shadows (sprite).

### VFX

`GPUParticles2D` library under `scenes/vfx/`: one emitter scene per element (`burn`, `chill`, `freeze`, `shock`, `toxin`, `mark`, `bleed`, `unravel`), per combo, hit sparks per weapon type, dodge trail, pickup sparkle, level/room clear burst, boss death. `Vfx.spawn(id, pos, tint)` through a pool in `World/FX`; spawned locally on every peer from replicated events. Each ability, relic proc, and mutation names its VFX id in its data so artists can swap without touching scripts. Compatibility renderer GPU particles are supported; cap simultaneous emitters at 128 with pooling.

### Audio

`AudioManager` autoload:

```gdscript
func play_music(track: AudioStream, fade_seconds: float = 1.5) -> void   # crossfade on two players
func play_sfx(id: StringName, pos: Vector2 = Vector2.INF, pitch_variance: float = 0.1) -> void   # pooled AudioStreamPlayer2D (positional) or non-positional
func set_bus_volume(bus: StringName, linear: float) -> void
func stop_music(fade_seconds: float) -> void
```

Buses: Master, Music, SFX, UI. SFX ids map to files in `assets/audio/sfx/<id>.ogg` via a `SfxBank` Resource; missing id logs once and plays a placeholder click. Positional SFX for hits, pickups, enemies; UI non-positional. Time effects do not alter pitch.

Music: town theme, 6 biome tracks, mini-boss theme, 5 biome boss themes, final boss track, main menu, victory, death. Placeholder loops week 1 to 11, final tracks week 12 (sourced CC0/CC-BY or composed; attribution file `assets/audio/CREDITS.md`).

SFX list (minimum): hit per weapon type (5), heavy hit, crit, dodge, perfect dodge, pickup gold/ore/echo/rune/relic, potion, ability cast per school (9), ultimate, class skill per class (7), enemy hurt small/large, enemy death, elite spawn, boss roar, door lock/unlock, room clear, rope, UI click/hover/confirm/cancel, dialogue blip, level-up/mastery.

### Final pass (week 12)

Replace placeholders for: all 4 player characters x 8 directions, 27 enemies + corrupted tint, 16 bosses, 6 tilesets, 11 buildings x 4 states, 8 NPC portraits + 4 character portraits + rescued miners, 88 relic icons, 30 ability icons, 19 weapon icons, 114 mutation icons (can be weapon icon + overlay), UI theme. Priority order if time is short: player sheets, Biome 1 to 3 tiles and enemies, bosses, icons, rest. Art quality decisions are the team's; this spec only fixes formats and naming.

## Interfaces provided

`AudioManager`, `Vfx` pool API and VFX id vocabulary, `SfxBank`, sprite sheet manifest format, tool scripts, import presets, naming rules, placeholder generator.

## Interfaces consumed

- `foundation`: `World/FX`, TileSet ids.
- `biomes`: palette and tracks.
- All content modules: `vfx_id` and `sfx_id` fields on `ContentData`-derived Resources (added to `ContentData` as optional fields under "Ask first" in week 1).

## Data model

`assets/**`, `SfxBank` at `data/audio/sfx_bank.tres`, `assets/audio/CREDITS.md`.

## Multiplayer ownership

Presentation only. VFX and SFX fire locally on each peer from replicated events; music follows local state (floor, boss).

Sync: none.

## Testing

- Integration `test_assets.gd`: every `ContentData` with an `icon` has a texture; every `vfx_id` and `sfx_id` referenced in `data/` exists in the libraries; every `SpriteFrames` has all 8 direction rows for every animation listed in its manifest.
- Unit `test_audio_manager.gd`: crossfade state machine, pool reuse, bus volume mapping.
- Perf: 128 emitters + 60 units at 60 FPS in the perf scene.
- Manual: weekly "does it look as crazy as it feels" check on a stacked build (design pillar 2).

## Success criteria

- [ ] Week 1: placeholder generator, import presets, `AudioManager` stub with placeholder SFX.
- [ ] Week 6: real player sheet, Biome 1 tiles, Biome 1 music, core SFX set.
- [ ] Week 12: final pass per priority list; every element, ability, relic proc has distinct VFX; every listed track and SFX present; credits file complete.
- [ ] No logic script references an asset path directly; all through data fields or banks.

## Open questions

- Art source: hand-drawn by the team, commissioned, or CC0 packs adapted. Decide by week 6; formats above apply regardless.
